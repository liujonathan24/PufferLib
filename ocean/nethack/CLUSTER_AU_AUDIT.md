# Cluster AU — remaining mutable file-scope globals in libnethack

Generated by `tools/find_globals.py` on 2026-05-22 after Clusters AT-A/B/C.

**~49 mutable file-static globals** across ~45 files. Each is a candidate
race surface at N>=128 vecenv (the canonical symptoms are NULL-source
`__memmove_avx_unaligned` crashes and `0xffffffff00000000`-pattern
pointer corruption).

## What's already migrated

Cluster A-AT covered: shop (5 vars), level/save filenames (4 vars),
dungeon graph (8 vars), TTY/window state, body-slot pointers, level
itself, flags/iflags/sysflags, timers, regions, light sources, NetHackRL
instance, and most arena bookkeeping.

## Migration pattern (DIRECT, not swap)

For each variable `T x;` or `static T x;`:

1. Add field to `nle_ctx_t` in `vendor/nle/src/include/nle.h`:
   ```c
   T s_x;          /* file.c: was static; per-env (Cluster AU) */
   ```
2. In the defining `.c` file, replace the storage with a macro:
   ```c
   #define x (current_nle_ctx->s_x)
   ```
   Place after `#include "hack.h"` (which transitively pulls `nle.h`).
3. If the variable's bare name collides with a struct field elsewhere,
   rename access sites and macro to e.g. `nle_x` (see `dgn_branches`
   pattern in AT-C `dungeon.c`).
4. If init was non-zero, either:
   - rely on `nle_start`'s calloc giving 0, and if non-zero needed,
     initialize on first env access (lazy), OR
   - explicitly set in `nle_start` after `calloc(nle_ctx_t)`.

## Tool

`tools/find_globals.py` — heuristic AST-free scanner for file-scope
mutable globals. Skips K&R-style param decls, const, typedef, struct
defs, `#define`, function decls. Run on whole repo:

```bash
python3 tools/find_globals.py --summary vendor/nle/src/src/*.c
python3 tools/find_globals.py --csv vendor/nle/src/src/*.c > audit.csv
```
